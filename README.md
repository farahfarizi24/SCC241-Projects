# SCC241-Projects Guide

All SCC241 Source Files will be gradually published in this repo. To use it within your team so everyone can collaborate easily here's my guide on the best approach:
  1. Clone the repository into one of the team member's github account, creating new team repository.
  2. Add the other member into that team repository
  3. Coding can be done through github codespace. Click code, choose codespace instead of local.
  4. Proper development and previewing the project can be done by opening the codespace on visual studio code and installing Live Preview add on https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server
  5. Make sure to gradually commit, push, and pull your changes. Communicate well with your team to solve all the merge conflicts
